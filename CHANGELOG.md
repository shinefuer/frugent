# Changelog

版本遵循 patch-only 序列，记录可验证的 library/CLI/schema 变化。

## 0.1.2 - 2026-10-30

- 增加 checksummed replay session、bounded loopback mock 与 adapter-driven runtime planning。
- 将 prefix route、prompt cache、micro-batch 和 hard-budget admission 接入完整离线 pipeline。
- trace 与 cost report 记录实际 stage counts；CLI 输出 paired synthetic measurement。

## 0.1.1 - 2026-10-30

- 稳定 public facade、strict record parsing 与完整 CLI/examples。
- 加入 CI matrix、wheel smoke test、security/contribution guides 与 reproducibility docs。

## 0.1.0 - 2026-10-30

- 建立 deterministic runtime types、configuration、fictional rate card 与 canonical artifacts。
- 实现 cache、compression、batching、cascade、budget、trace、sandbox 和 agent loop mechanics。
- 加入 seeded synthetic workload、paired evaluation、reports、CLI、examples 与 optional CPU torch demos。
- 默认测试完全离线；未包含真实 endpoint、provider price、pretrained weight 或外部 dataset 结果。
